# Bash Scripting Fundamentals

Small, numbered Bash exercises for learning variables, command-line arguments, and shell expansion.

## Learning sequence

| File | Focus |
|---|---|
| [01-hello-world.sh](01-hello-world.sh) | Placeholder for the first exercise |
| [02-conversation.sh](02-conversation.sh) | Printing a conversation |
| [03-variables.sh](03-variables.sh)–[05-variables.sh](05-variables.sh) | Variable examples |
| [06-special-vars.sh](06-special-vars.sh) | Special shell variables |

## Try an exercise

Requires Bash and Git on Linux, macOS, or WSL.

```bash
git clone https://github.com/hareeswarreddymandedi/shell_practice.git
cd shell_practice
bash -n 02-conversation.sh
bash 02-conversation.sh
```

Read each file before running it. Start with the numbered examples and compare the output with the variable values. These are introductory exercises, not a production automation toolkit.
